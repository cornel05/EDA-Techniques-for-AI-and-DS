Note on DistilBERT results: The near-perfect accuracy (99.99%) is expected for this task. Question type classification based on the first word is a lexically trivial problem for a pre-trained transformer — the first token ("What", "Who", "When"…) is a near-perfect predictor. The value of fine-tuning here lies in demonstrating the pipeline, not in the difficulty of the task itself.
